### Project Description
The pomodoro timer has 3 modes: pomodoro, which is 25 min long; short break, which is 5 min long; and long break, which is 15 min long. Once the tine interval is completed, an audio plays to congratulate the user. The start button toggles into a reset button so the user can restart the interval if desired.
